Installation

  1. Télécharger le fichier arm64 (la plupart des téléphones depuis 2017).
  2. Ouvrir le fichier téléchargé ; autoriser l'installation depuis le navigateur si Android le demande.
  3. Première installation par-dessus une version de développement : désinstaller l'ancienne d'abord (signature différente). Les données sont dans le compte, rien n'est perdu.

Android peut afficher un avertissement Play Protect parce que l'application lit les SMS bancaires (import automatique, optionnel). Vérifier l'empreinte SHA-256 ci-dessus en cas de doute. SHA256SUMS.txt · latest.json
